# Progetto-Cinemax

Autori:
- Caputo Samuele, matricola 765173, VA
- Alessandra Larghi, matricola 765304, VA

il programma è un sistema per piccoli cinema monosala da 200 posti, che
permette di gestire il proprio palinsesto (quali film sono disponibili ed in che giorni) e gestire le prenotazioni dei clienti.

il programma permette:
- ai proiezionisti di definire quali film verranno proiettati e in quali giorni;
- ai bigliettai di creare le prenotazioni dei clienti;
- ai clienti di cercare le proiezioni in base alle caratteristiche desiderate, quali il titolo del film, il genere, la data o il costo del biglietto; oppure di prenotare posti in sala per una proiezione.


Requisiti:
- Java 21 o superiore

Istruzioni di avvio:
1. Scaricare il progetto da GitHub come ZIP ed estrarlo
2. Aprire il terminale (cmd) nella cartella del progetto
3. Eseguire il comando:

   java -jar bin\CineMax.jar

assicurarsi di trovarsi nella cartella radice prima di lanciare il comando in questo modo Java trova la cartella data/ con i file riguardanti le proiezioni, prenotazioni e utenti.
